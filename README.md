# Government Services Analytics Project

## About Project
This project analyzes citizen complaints submitted to government service departments to improve operational efficiency and support better decision-making.

The analysis focuses on four main sectors: Electricity, Water, Roads, and Garbage.

---

## Problem Statement
Managing large volumes of citizen complaints can be challenging due to multiple data sources, inconsistent formats, and limited monitoring capabilities.

These issues often lead to delayed responses, weak prioritization, and reduced service quality.

This project was developed to organize complaint data, improve tracking, and provide clear insights into service performance.

---

## Dataset
The dataset contains complaint-related information including issue type, department, priority, status, dates, satisfaction score, location, and submission channel.

A total of **2,000 complaints** were analyzed.

---

## Project Workflow

### Data Preparation
The data was collected in different file formats including CSV, Excel, and Flat Files. Cleaning and transformation steps were applied to handle missing values, standardize formats, and prepare the data for analysis.

### Database Design
A structured database model was created to organize the data efficiently and reduce redundancy.

### Data Processing
An ETL workflow was implemented to transform, clean, validate, and load the data into the final database.

### Dashboard Creation
Interactive dashboards were built to monitor complaint trends, service performance, complaint status, and customer satisfaction.

---

## Tools Used
SQL Server, SSIS and Power BI  

---

## Outcome
This project delivers a complete solution for organizing and analyzing government complaints, helping improve service monitoring, complaint tracking, and operational decision-making.
